# Repo map (for reviewers)

Two products in one repo: a licence panel (Node.js on Vercel + Supabase) and
the Android loader app `com.xlox` (Java + XML Views, built in GitHub Actions).

## Top level

| Path | What it is |
|---|---|
| `web/` | Licence panel. Vercel root directory. |
| `xlox/` | Android app (Gradle project, module `app`). |
| `supabase/` | `schema.sql` (full schema) and `migrations/` (applied changes). |
| `.github/workflows/` | CI: APK build + release, QA, update e2e, live smoke test. |
| `README.md`, `DEPLOYMENT.md` | Overview; infrastructure, env vars, verification. |
| `INTEGRATION.md`, `API.md` | Loader ⇄ panel contract (`/connect`, lib, app update); key REST API `/api/v1`. |

## Android app (`xlox/app/src/main/`)

- Screens (`java/com/xlox/`) → layouts (`res/layout/`):
  `SplashActivity` → `activity_splash` · `AppUpdateActivity` → `activity_app_update`
  · `LogAct` (sign in) → `activity_login` · `MAct` (home + Settings) → `activity_main`
  and bottom sheets `sheet_*.xml` · `ui/UpdateGate` (library gate) → `dialog_update`.
- Theme and tokens: `res/values/{colors,styles,dimens,motion,strings}.xml`;
  fonts `res/font/` (Inter, JetBrains Mono); helpers `ui/Ui.java`.
- App (APK) update: `utils/AppUpdater.java` (check, download, verify, PackageInstaller).
- Library update: `utils/Downtwo.java` (download + verify), `utils/LibManager.java`
  (install / load `libbgmi.so`), `ui/UpdateGate.java` (UI).
- Network / errors: `utils/Net.java`, `utils/UpdateException.java`.
- Licensing and `/connect`: native, `jni/main.cpp`; all panel URLs and the
  token salt in `jni/panel_config.h`.
- Launch / OBB copy / container: `utils/AppManager.java`, `BoxApplication.java`,
  `libs/mundo-release.aar` (container SDK). Permissions: `utils/StorageAccess.java`,
  `ui/PermissionSheet.java`, `AndroidManifest.xml`.
- Build config: `xlox/app/build.gradle` (version, signing from env/secrets,
  lint baseline, NDK 24). Release key `xlox/app/xlox.jks` (passwords are CI secrets only).

## Panel (`web/`)

- Entry: `api/index.js` → `src/app.mjs` (the router: every page and API route).
- Route handlers: `src/licensing.mjs` (`/connect`, `/api/health`, `/api/lib/*`),
  `src/app-release.mjs` (`/app-update`, `/api/app/update`, APK link check),
  `src/key-service.mjs` (key creation/charging), `src/api-keys.mjs` (`/api/v1`),
  `src/auth.mjs` (sessions), `src/http.mjs`, `src/render.mjs` (CSP, rendering).
- Views: `views/*.hbs` (Handlebars). `src/templates.generated.mjs` and
  `src/icons.generated.mjs` are generated by `scripts/build-*.mjs` and committed.
- Static: `public/assets/` (ui.css, app-ui.js, fonts).
- Database: `src/db.mjs` (Supabase client; `memory-db.mjs` for tests);
  schema in `supabase/schema.sql` + `supabase/migrations/`.
- Tests: `npm test` (`scripts/smoke-test.mjs`, in-memory DB), `scripts/check.mjs`.

## CI and releases

- `build-xlox.yml` (push to `xlox/**`): UI gates → signed release APK → lint →
  APK permissions + 16 KB ELF checks → GitHub release
  `anoy-v<versionName>-<versionCode>` (Latest); all other releases/tags deleted.
  Nothing is committed back; artifacts are kept 7 days.
- `web-ui-qa.yml` (push to `web/**`): panel tests + screenshots (artifact).
- Manual: `android-ui-qa.yml` (emulator screenshots), `app-update-e2e.yml`
  (real update download → installer), `live-smoke.yml` (live panel checks).
- Panel production deploy: Vercel project `anoymundo-panel` from this branch,
  function region `bom1` next to Supabase `ap-south-1` (pushes create previews;
  production is promoted on demand).
- Phones get an app update only after the owner publishes it at `/app-update`.

## Hard limits (do not change)

- Licensing protocol and `POST /connect` (request, response, token check, salt).
- JNI / native code contract (`jni/`, `panel_config.h`).
- Launch flow and OBB copy (`AppManager`), container SDK, permission requests.
- `targetSdk 28`, `minSdk 21`, `applicationId com.xlox`, the signing key.

Removed clutter (old screenshots, QA logs, source archives, one-off generator
scripts referenced in some resource comments) is in git history.
