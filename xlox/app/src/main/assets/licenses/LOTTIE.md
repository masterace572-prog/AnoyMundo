# Lottie animations — provenance

The app ships three local Lottie JSON resources in `res/raw/`. They never load
at runtime from LottieFiles: the APK contains the exact animation it needs, so
the splash works before a network connection exists.

| File | Use | Length | Size | Source |
|---|---|---:|---:|---|
| `anoy_splash.json` | Full-screen black-and-white launch film; direct vector edit to **AnoyHax** and final **A** | 6.67 s | ~139 KB | Rebranded derivative of Techpost, below |
| `anoy_arc.json` | Quiet white arc while Splash checks for an app update | 2.4 s | ~1 KB | Original Anoy work |
| `anoy_check.json` | Blue ring and tick for Splash “Up to date” | 0.7 s | ~2 KB | Original Anoy work |

## Anoy splash / Techpost attribution

- **Original:** “Techpost” animation by **Danilo Granatto** on
  [LottieFiles](https://lottiefiles.com/free-animation/techpost-sr3iDgDemF).
- **Licence:** [Lottie Simple License](https://lottiefiles.com/page/license).
- **Source retained:** `xlox/third_party/lottie/techpost.json`, SHA-256
  `4e50ebe64cc4d931082950639b13bdd2c0a92952c8254367b28638e72c5a8565`.
- **Anoy derivative:** `xlox/scripts/lottie_art.py` is the source of truth for
  `res/raw/anoy_splash.json`. It doubles the source timeline to 60 fps and
  recolours it to white on true black. It directly rebuilds the seven existing
  final-word vector slots as `A n o y H a x`, disabling the source's paired
  counter/matte paths rather than painting complete replacement glyphs over
  them. The later standalone `T` vector is likewise replaced by `A`. There is
  no overlay, blackout layer, native `TextView`, or added Lottie text layer.
  `scripts/anoy_splash_glyphs.json` stores the reproducible Inter Semibold
  vector outlines used by that edit. The source animation is retained for
  provenance but is not packaged in the APK.

The two small status animations are original work authored in this repository
and generated by the same Python script. They are stroke-only (1.75 dp), with
no fills, images, masks or expressions. Their reduced-motion behaviour is
handled by `com.xlox.ui.Motion`; Splash shows the final branded Lottie frame
without motion when Android animations are disabled.
